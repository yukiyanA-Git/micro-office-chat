# ⚡ ウルトラコンパクト・オフィスチャット (Micro Office Chat)

PC画面の右上（画面比 1/15）に常駐固定できる、仕事のちょっとした声掛け・確認事項専用の超軽量リアルタイムチャット掲示板です。

---

## 🌟 特徴・機能

1. **画面1/15 ウルトラコンパクトサイズ (330px × 540px)**
   - 仕事の作業画面を邪魔しないスマートなアクリル・ダークデザイン。
   - 画面上の好きな場所（右上、左下、サブモニター）へドラッグ移動でき、最前面ピン留め（📌）トグル可能。

2. **ワンタップ・クイック声掛けスタンプ**
   - `[ 〇 了解 ]` `[ ✕ NG ]` `[ 🤔 考え中 ]` `[ 📞 連絡 ]` `[ 👀 確認中 ]` `[ 🏃 離席 ]`
   - ワンタップで即座に状況を相手に送信できます。

3. **最大3つの常設グループ切り替え (タブ機能)**
   - `[ 営業チーム ]` `[ 開発Bチーム ]` `[ 全体連絡用 ]` をワンタップで切り替え。
   - パスコード（合言葉）保護により、情報漏洩を防ぎ関係者のみが接続可能。

4. **オンラインフレンド在席表示 (苗字の先頭1文字アバター)**
   - メンバーの苗字から先頭1文字（例: 「山」「佐」）を抽出しアバター化。
   - リアルタイムで 🟢 在席 / 🏃 離席 / 📞 会議中 がひと目で把握可能。

5. **便利なログ管理**
   - **一括消去ボタン (🧹)**: ワンタップでたまったログを全消去して画面をスッキリ整理。
   - **全コピーボタン (📋)**: チャットログをテキスト形式でクリップボードへ一括コピー。手元のメモ帳へペースト保存可能。
   - **個別削除 (✕)**: 間違えて送信したメッセージを個別削除。

6. **PC画面右下デスクトップ通知**
   - チャット画面が他のウィンドウの後ろに隠れている時、声掛けが届くと画面右下にOSポップアップ通知。

---

## 🚀 起動・使用方法

### ローカルサーバー起動
1. 本フォルダで `node server.js` を実行。
2. ブラウザで `http://localhost:3000` を開く。
3. 右上の `↗️`（小窓ボタン）を押すと、デスクトップ専用のポップアップウィンドウとして右上に固定表示されます。

### Firebase 連携（完全ノードレスクラウド運用）
1. `public/firebase-config.js` に今お持ちの Firebase Realtime Database のキーを入力。
2. サーバー構築不要で、世界中どこからでもネット越しにリアルタイム同期接続が可能です。
